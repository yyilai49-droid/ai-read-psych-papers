- 在线版：<https://yyilai49-droid.github.io/ai-read-psych-papers/>
- 纸质版：[`ai-read-psych-papers.pdf`](ai-read-psych-papers.pdf)（16 页，中文单语）

## 关于准确性

手册里对统计学与方法学的表述遵循一条原则：**只写能站得住的内容**。

- 明确区分 p 值与效应量，不把「显著」当作「效应大」
- 强调置信区间与检验力，说明不显著结果在低检验力下说明不了什么
- 反复提示 AI 无法可靠核实文献，核实必须回到数据库
- 模型能力迭代较快，工具章节给的是挑选标准而非排行榜，并已注明「以使用时为准」

## 使用

单文件 `index.html`，无构建步骤。除一个 Google Fonts 外链（断网时回落到系统字体）外无外部依赖。

- 直接在浏览器打开，无需登录
- 右上角切换中英文，选择记在 `localStorage`
- 左上角按钮切换深浅色，默认跟随系统
- 桌面端左侧有章节导航，手机端为单栏
- Prompt 模板块右上角有复制按钮

## PDF

`@media print` 样式表在打印时：

- 强制中文单语（隐藏英文对照）
- 隐藏顶栏、章节导航与复制按钮
- 展开全部自测答案
- 避免在 Prompt 块、表格、卡片内部断页

重新生成：

```bash
msedge --headless=new --disable-gpu --no-first-run \
  --virtual-time-budget=12000 --no-pdf-header-footer \
  --print-to-pdf=ai-read-psych-papers.pdf index.html
```
